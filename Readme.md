# Mauri
---
Скрипт собирает данные товаров книг с сайта [books.ru](https://www.books.ru/). Для сбора данных используется библиотека BeautifulSoup, request. Скрипт работает на PostgreSQL, который установлен в Docker контейнере. Для работы приложения нужно его поднять.
## Основные команды
---
- Парсинг html страницы можно сделать следующей командой:
```bash
python3 main.py parse
```
В файле parse.conf переменные отвечают за обновление файла html, с которого и парсятся данные.
- Вывод данных в консоль из БД:
```bash
python3 main.py books list
